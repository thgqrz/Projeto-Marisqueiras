# Projeto-Marisqueiras
Sistema desenvolvido em Python utilizando Programação Orientada a Objetos (POO) para o projeto Marisqueiras da Ilha Upaon-Açu. A aplicação permite o cadastro e gerenciamento de produtos, consulta e comparação de ofertas, realização e acompanhamento de pedidos, controle de estoque e avaliação das empresas.
